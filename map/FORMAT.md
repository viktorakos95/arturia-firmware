# Map format

`firmware.json` is curated metadata for the original KeyStep 37 application
1.1.6.579. `index.md` and `calls.mmd` are generated by `render.py`.

- `image`: exact application segment base, length and SHA-256. A supplied
  container must also pass the toolkit's whole-file profile and integrity checks.
- `nodes`: stable ID, kind, even code address or separately typed data address,
  provisional label, status, summary, short identity windows and optional fields.
- `evidence`: absolute flash address, byte length and SHA-256 of a 1–16-byte
  window. Digests identify a location without reproducing its payload. They do
  not independently prove the semantic summary. RAM facts refer to code/literal
  evidence in flash, not a device RAM dump.
- `fields`: observed offsets and sizes; absence of a field means unknown, not
  padding or free memory. A field inventory is not a class-size declaration.
- `edges`: source/target IDs, explicit kind, condition and status. `direct_call`
  adds the actual even BL site and hashed instruction identity. `indirect_call`
  is a virtual-dispatch relationship with narrower coverage. `function_pointer`
  describes data containing a callable pointer. `contains`, `data_reference`,
  `data_access`, `data_write`, `conditional_path` and `shared_buffer` are not
  call edges.
- `questions`: unresolved behavior with a concrete next investigation.

`confirmed_static` means that a relation was traced in this exact image.
`supported` retains incomplete context. `hypothesis` requires further evidence.
Hardware observations and host models belong in separate documents or test
reports; none of these map statuses means device validation.

Instruction address `0x08013e8c`, callable Thumb pointer `0x08013e8d`, RAM
consumer `0x20004ed4`, and vtable address `0x0801e9a8` are four different
values with different roles.

After editing metadata:

```sh
python3 map/render.py
python3 map/render.py --check
python3 map/check.py --firmware "$KS37_STOCK"
```

The call graph renders selected direct calls as solid edges and virtual/pointer
relationships as dashed edges. Conditions remain in JSON; the graph is not a
complete execution trace or control-flow graph.
